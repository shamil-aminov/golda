## Варианты (раунд 2, текущий)
[home-details/prototype.html](home-details/prototype.html), кадр [home-details/prototype.png](home-details/prototype.png).
Полоса темпа **заменена** одним элементом; текст — те же две строки. Тёмная Zinc-тема, 411×891, данные одни на всех
(SPEC §5: 31 ₾ сегодня, хватит на 14 из 23, план 43 · факт 67; период 32 дня, сегодня 10-й).
1. **Полоса периода с отметкой «сегодня»** — заливка = доля ушедших денег, риска = доля прошедшего времени. Просто,
   но сегодняшнюю долю говорит только цифра.
2. **Дни периода, сегодня внутри** — полоса из кусочков-дней: прошедшие серые, сегодня шире и залит остатком дня (как
   нынешняя полоса), дни, на которые хватит, — светлые, на которые не хватит, — пустые контуром. Несёт и сегодня, и
   период, и «хватит на 14 из 23». Данные есть в `Envelope` (`start`, `end`, `daysLeft`, `runwayDays`, `leftTodayMinor`).
3. **Столбик на день** — высота = траты дня, сегодня — доля дня, впереди — план, пока хватает. Больше всего сведений,
   шумнее всех.
4. **График остатка** — линия денег на карте, пунктир плана и пунктир темпа к нулю. Сегодняшней доли не видно.
- **2 + строка** — рекомендация; единственная новая строка «Ещё спишется 85 ₾: интернет, связь» по желанию.

## Вопросы
- Чем заменить полосу темпа? — 1, 2, 3, 4 — **рекомендую 2 «Дни периода»**: единственный, где видно и остаток
  сегодняшнего дня, и весь период, и где кончатся деньги; рисуется теми же скруглёнными плашками, без графиков.
- Брать ли новую строку «Ещё спишется 85 ₾: интернет, связь»? — да / нет — **рекомендую да**, только показывать, не
  вычитать из «на день» (вычитание меняет главную цифру за человека).
- Период длиной в месяц — 30+ кусочков по ~8 dp; для недели кусочков 7–8, они шире. Нормально ли, что вид полосы
  зависит от длины периода? — **рекомендую да**: так и видно, что период короткий.

## Подводные камни
- Пользователь: элемент на плитке **один**. Ничего не добавлять рядом с полосой — только заменять её.
- Дни в периоде: последний день ещё в нём (SPEC §5.1), месяц с 26 октября — 32 кусочка, `daysLeft` считает сегодня.
  Кусочки «не хватит» = `daysLeft − runwayDays`; без бёрна (`runwayDays == null`) — все светлые.
- В бёрн разовые не входят, а в «ушло» (вариант 1) — входят (это деньги с карты).
- Цвет — по-прежнему цвет темпа (`paceColor`): перерасход за сегодня красит сегодняшний кусочек и светлые дни.

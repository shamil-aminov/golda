## Подводные камни
- Знаки: `Currencies.symbol` знает 11; для остальных берётся системный (`Currency.getSymbol`), если он не код и
  не длиннее 2 знаков (AUD → A$, INR → ₹). Сторонние знаки на телефоне могут отличаться от Robolectric.
- Страна — из первых двух букв кода ISO 4217 (`GEL` → `GE`), «EU» → «Европейский союз» (укорочено до «Еврозона»).
- Порядок на открытой странице фиксирован (`remember` в `CurrencyPage`) — карточка не прыгает под пальцем; в «б»
  нажатая в списке валюта появится в карточках только при следующем открытии, либо добавлять ряд на лету — решить при
  сборке.
- Для местной/основной (`CurrencyPick.LOCAL/BASE`) выбор одной закрывает страницу — карточки работают так же.
- Другие места выбора валюты (`AccountSheet.AccountCurrency`, `OperationSheet.CurrencyPicker`) — ряд знаков, не
  список; задача их не трогает.

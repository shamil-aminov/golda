# Настройки и Тема — второй контур
Статус: ждёт пользователя (выбор варианта) · Обновлено: 2026-11-04

## Цель
Разобрать Настройки и страницу «Тема» по блокам, как Аналитику: самое нужное — сразу, уточнения — уровнем ниже.
Чисто и собранно, как Главная и «Счета». Логику настроек не менять; цвета и устройство тем — отдельная задача
(бэклог, «строгая система цветов»).

## Решения пользователя
- 2026-11-04: «когда мы будем работать над вторичными контурами, мы дойдем и до тем, потому что там тоже уже столько
  настроек стало, что необходимо структуризация. Подобного же вида, как и над аналитикой… я думаю, что мы будем
  тестировать все на дефолтной теме, которая у нас есть. А все остальное, там связано с деталями… самих тем и их
  устройства… это уже потом.» «Вторые контуры можно потихоньку брать. Но не слишком много сразу».
- Подход как у Аналитики: «берем все блоки… обособленно… думаем, насколько они важны… самое важное полезное вынесено
  сразу… если требуется уточнить… проваливаемся на уровень ниже… чистым и собранным, как главное и счета».
- Подсказок и поясняющих подстрок в интерфейс не добавлять.

## Инвентарь (как есть, `SettingsScreen.kt`, `ThemeScreen.kt`)
Частота — оценка: «часто» — в поездке или каждую неделю, «редко» — раз в месяцы, «раз» — при настройке.

**Настройки** — один длинный экран, 8 карточек, 18 строк (кадр `now.png`, слева).

| Карточка | Пункт | Что делает | Тип | Частота |
|---|---|---|---|---|
| Где я | Местная валюта | валюта новых трат и голоса | выбор → страница валют | часто (поездка) |
| | Основная валюта | валюта крупных цифр и итогов | выбор → страница | редко |
| | Валюты | какие валюты показывать | множ. выбор → страница | редко |
| Курс | Наценка к ЦБ | % к курсу ЦБ, сама подстраивается после обмена | число → лист | редко |
| | 1 $ = …, 1 ₾ = … | курс с наценкой и ЦБ | только показ, по строке на валюту | смотрят часто |
| | Обновить курс | тянет курс ЦБ | действие | редко |
| Gemini | Ключ Gemini | ключ API | ввод → лист | раз |
| | Модель для голоса | выбор модели | выбор → лист | раз |
| | Модель для разборов | выбор модели | выбор → лист | раз |
| | Не разобрано: N | голосовые без ответа (только когда есть) | действие → лист | при сбое |
| Данные | Сохранить копию | файл JSON | действие → системный выбор | редко |
| | Восстановить | заменить всё файлом | действие + подтверждение | редко |
| | Копия каждую неделю | папка и автокопия | переключатель + выбор папки | раз |
| Напоминания | Напоминать о сверке | воскресенье 19:00 | переключатель | раз |
| Оформление | Тема | открывает «Тему» | переход | редко |
| Язык | Язык приложения | рус / англ / как в системе | выбор → лист | раз |
| — | Стереть всё | удаляет всё | опасное + подтверждение | почти никогда |

Подстроки сейчас частью — пояснения, а не значения («, для новых трат и голоса», «Всё, кроме ключа, в один файл»,
«В папку, которую выберешь, хранятся последние 4»): по правилу «без подсказок» — под вопросом.

**Тема** — один экран, 9 блоков (кадр `now.png`, справа).

| Блок | Что | Тип | Частота |
|---|---|---|---|
| Светлая или тёмная | как система / светлая / тёмная | выбор из 3 | редко |
| Чистый чёрный | тёмная на #000 | переключатель | раз |
| Цветные траты | кружки в цвете категории | переключатель | раз |
| Плотность списков | плотно / обычно / просторно | выбор из 3 | раз |
| Спокойные | 12 тем | сетка чипов | редко (выбор темы — главное здесь) |
| Смелые | 8 тем | сетка чипов | редко |
| Сохранённые | свои (только если есть) | сетка, долгое нажатие — удалить | редко |
| Своя из одного цвета | 12 оттенков, ползунок, «Из обоев», «Случайная» | генератор | раз |
| Стиль, Контраст | 4 и 3 варианта генератора | выбор | раз |
| (шапка) | «Сохранить» свою / удалить сохранённую | действие | раз |

Наблюдения: на «Теме» выбор темы — главное — начинается только после трёх настроек вида; генератор (12 кругов,
ползунок, две кнопки, два выбора) занимает половину экрана, хотя нужен один раз. В Настройках строки курса — не
настройки, а справка; «Тема» и «Язык» — по карточке на одну строку.

## Рекомендация
**А.** Местная валюта и курс — то, ради чего заходят в поездке, — остаются в одно касание, как сейчас; редкое и
разовое (Gemini, копии, стереть) уходит на уровень ниже и не мешает. На «Теме» выбор темы поднимается наверх под
режим, а генератор и тонкие настройки — по строке. Б чище на первом экране, но каждое действие — на касание дальше,
и сводки в подстроках разделов становятся длинными. Логика не меняется: те же пункты, листы и подтверждения,
меняется только где они лежат.

## Вопросы
- **А или Б?** Рекомендация — А.
- **Пояснения в подстроках** («, для новых трат и голоса», «Всё, кроме ключа, в один файл», «В папку, которую
  выберешь…»): убрать, оставив только значение (как в прототипах)? Рекомендация: да — по правилу «без подсказок»;
  что делает пункт, говорит его лист.
- **Строки курса** (1 $ = 101,2 ₽ · ЦБ 92): по строке на валюту, как сейчас, или одной подстрокой у «Обновить курс»
  (как в А)? Рекомендация: подстрокой — это справка, не настройка.
- **Значки у строк Настроек**: без значков (как «Счета», в А) или со значками (как оглавление в Б)? Рекомендация: без
  значков в А; в Б оглавлению значки нужны.
- **«Тонкие настройки»** — название; или «Списки и экран»? Рекомендация: «Вид списков» — точнее, если чистый чёрный
  туда тоже входит, то «Тонкие настройки».

## Подводные камни
- Строка «Не разобрано: N» появляется только при сбое голоса: во втором уровне её не увидят — в А стоит показать её
  и на первом экране, пока она есть (как сейчас), или подстрокой «Голос и разборы».
- Выбор папки для недельной копии — системный, разрешение держится (`takePersistableUriPermission`); переносить
  вместе с переключателем.
- Шапка «Темы» меняет действие («Сохранить» / удалить) по состоянию генератора — при выносе генератора на свою
  страницу действие переезжает с ним.
